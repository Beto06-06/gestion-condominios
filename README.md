Sistema web para centralizar la administracion de apartamentos y condominios

Objetivo:
Mantener toda la informacion del condominio organizada en un solo sistema y faciltar las tareas administrativas y de control de residentes, filiales, alquileres, visitantes, parqueos, reservas de areas comunes,
mantenimiento y bitacoras de guardas.
